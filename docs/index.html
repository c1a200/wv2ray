客户端使用指南
Clash / FlClash 客户端配置
  1. 复制 Clash 专属订阅 链接；
  2. 打开 Clash / FlClash，进入「配置」或「Profiles」界面；
  3. 粘贴复制好的链接到输入框，点击「下载」或「Import」导入；
  4. 导入完成后选中该配置文件，在「代理/Proxies」中挑选延迟较低的节点使用。
v2rayN (Windows) 客户端配置
  1. 复制上面的 V2ray / 通用订阅 链接；
  2. 打开 v2rayN，在顶部菜单选择「订阅管理」->「添加」；
  3. 在「地址(url)」栏粘贴链接，并点击「保存」；
  4. 保存后返回主界面，点击顶部「订阅」->「更新订阅」，等待节点导入完成即可使用。
Shadowrocket (iOS 小火箭) 配置
  1. 在 iPhone 浏览器上直接点击 导入 小火箭 一键导入；
  2. 或者复制 V2ray / 通用订阅 地址或生成其二维码；
  3. 在小火箭中点击右上角「+」，类型选择「Subscribe」，粘贴链接保存，或者点击左上角扫描二维码导入。
